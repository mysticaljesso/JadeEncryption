# Jade Encryption

Jade Encryption is a revived C# encryption tool originally created as my first programming project. After years of abandonment, I decided to bring it back to life, clean it up, and prepare it for a modern future. Version **1.1.1** is a small maintenance update, but the project is officially active again.

---

## About the Project

Jade Encryption provides a simple workflow for encrypting and decrypting data using a lightweight interface and straightforward logic. It’s designed for personal use, experimentation, and as a foundation for a more advanced encryption system planned for future releases.

This repository contains the full source code, update notes, and development roadmap.

Website: **https://jessicaamy.com**  
Contact: **contact@jessicaamy.com**

## Current Version – 1.1.2
Code
This commit retires the original 2016 Jade Encryption codebase.

Changes:
- Renamed UI and metadata to "Jade Encryption Classic"
- Fixed the long-standing SharpAESCrypt.dll path issue under MSIX sandboxing
- Updated About box with GPLv3, attribution, and final release notes
- Ensured full compatibility with old SimpleCrypt files
- Added final version header comments and cleaned UI text
- Project now ready for GitHub release and Microsoft Store (v1.1.2)

Farewell to the classic version — Jade Encryption 2.0 will be a brand new codebase.

## Roadmap – Version 2.0 (In Development)

A major rewrite is underway. Version **2.0** will introduce:

- A modern, more secure encryption engine  
- Support for selecting different ciphers  
- Expanded configuration options  
- Cleaner architecture and improved code structure  
- Additional features and quality-of-life improvements  

Development will continue once I finally eat my ham, which will fuel the next generation of Jade Encryption.
