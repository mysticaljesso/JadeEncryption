Jade Encryption is a revived C# encryption tool originally created as my first programming project. After years of abandonment, I decided to bring it back to life, clean it up, and prepare it for a modern future. ## About the Project

Jade Encryption provides a simple workflow for encrypting and decrypting data using a lightweight interface and straightforward logic. It’s designed for personal use, experimentation, and as a foundation for a more advanced encryption system planned for future releases.

This repository contains the full source code, update notes, and development roadmap.

## Current Version – 1.1.2
Code
This commit retires the original 2016 Jade Encryption codebase.

Changes:
- Renamed UI and metadata to "Jade Encryption Classic"
- Fixed the long-standing SharpAESCrypt.dll path issue under MSIX sandboxing
